# Cormier Realtime 1.0.6-beta

This coordinated release updates the gateway application and container, Helm chart, .NET and browser packages, automation scripts, and reference applications to `1.0.6-beta`.

## Changes

- Added a production-shaped high-availability bootstrap example with configuration-driven Redis credentials and certificate management.
- Hardened managed Redis Sentinel startup, recovery, DNS discovery, chart provenance, credential validation, and HTTP/WebSocket route validation.
- Updated GitHub Actions and custom-runner configuration used by the repository's validation workflows.
- Fixed the browser HTTP-streaming transport so its default Fetch API retains the required browser receiver, with regression coverage and rebuilt distributable assets.
- Updated the locked Elixir Mint HTTP client to `1.11.0` to address the September 28, 2026 security advisories.

## Compatibility and upgrade notes

- This is a coordinated prerelease version update; no protocol version or public API compatibility boundary changed.
- Operators using managed Redis HA should review `bootstrap/config.ha.example.json` and `docs/runbooks/managed-redis-ha.md` before applying the updated bootstrap workflow.

## Release integrity

- Publication requires successful main-branch CI for the exact source commit.
- NuGet packages, the gateway image, and the public Helm chart use the same coordinated version.
