# Cormier Realtime 1.0.2-beta

This coordinated beta release establishes one version across the gateway application and container, Helm chart, .NET and browser packages, automation scripts, and reference applications.

## Release artifacts

- `Cormier.Realtime.Contracts`, `Cormier.Realtime.Client`, `Cormier.Realtime.Redis`, `Cormier.Realtime.AspNetCore`, and `Cormier.Realtime.Browser` NuGet packages
- `@cormier/realtime` npm candidate package and generated browser assets
- immutable realtime gateway container, tagged by both source commit and `1.0.2-beta`
- `realtime-gateway-1.0.2-beta.tgz` Helm chart
- versioned PowerShell deployment, bootstrap, package, and verification scripts
- coordinated ASP.NET Core, .NET client, Go, Node.js, Java, Kotlin, Rust, Python, PHP, Ruby, Elixir, and Swift reference applications

## Release integrity

- Package publication uses NuGet Trusted Publishing with a short-lived OIDC credential.
- The release is built only after successful `main` CI and uses the exact tested source commit.
- Package candidates include checksums, a vulnerability scan, an SBOM, and provenance evidence.
- Container promotion remains digest-based; the semantic tag is an additional immutable release coordinate.
- Automatic publication covers NuGet. npm publication remains a manual opt-in until registry ownership and credentials are approved.

## Compatibility

The wire protocol remains `1.0` and the WebSocket subprotocol remains `cormier.realtime.v1`. This beta coordinates artifact versions without introducing a protocol break.
